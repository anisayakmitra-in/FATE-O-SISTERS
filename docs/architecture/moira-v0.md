# MOIRA v0 Architecture Specification

- Status: superseded
- Replacement: [`MOIRA Offline Lifelong-Cognition Architecture v1`](moira-lifelong-v1.md)

MOIRA v0 recorded the first Phase 0 design. It used a fixed root assumption and
a nonstandard precision policy that the executable research contracts have
since replaced.

The v1 specification is normative for model identity, persistent perspective
registers, root-relative threefold growth, standard numeric precision, lifelong
learning, control authority, capability qualification, cybersecurity, and
offline Consumer and Enterprise deployment.

The full v0 text remains available in Git history for design archaeology. It
must not be used to generate current manifests, commands, checkpoints,
qualification claims, or deployment policy.
